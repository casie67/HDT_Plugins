# HDT 酒馆战棋插件


| 文件夹 | 插件名 | 作用 |
|---|---|---|
| `HDT_BGSessionFilter` | 全绿战绩器 | 隐藏会话面板里掉分的对局，并重算起始分 |
| `HDT_BGCombatStats` | 狗运计算器 | 统计每轮战斗的预测胜率与实际胜平负（拔线也能统计） |

---

## 环境

基于 **HDT 1.57.6.0**

HDT 更新到新版本后，插件可能加载失败或行为异常。

---

## 安装

1. 在 HDT 里点 **选项 → 追踪器 → 插件 → 插件文件夹**
2. 把 `.dll` 复制进打开的那个目录
3. 重启 HDT
4. 在 **选项 → 追踪器 → 插件**，以及首页顶部的 **插件**，把插件开关打开

⚠️ **不要**放到 HDT 安装目录下的 `Plugins` 文件夹，那里的插件会在更新时被删除。

⚠️ 更新插件时**先删掉旧的 dll**。

---

## 全绿战绩器

### 已知限制

- **会话可能被切开**。HDT 用"上一局结束 → 下一局开始间隔 ≥ 2 小时"判定会话中断，删掉中间的对局会把前后空档合并，有可能跨过 2 小时，导致列表只剩后半段甚至变空。

### 做什么

在悬浮窗里统计每轮战斗的预测概率累加值，与实际胜平负次数并列显示：

### 为什么需要它

HDT 自己判定战斗结果靠的是日志里的攻击记录。**拔线**跳过战斗动画时，客户端收不到战斗过程，HDT 那一轮的结果就丢了。

本插件改用**英雄血量差**判定，只看战斗前后的状态、不依赖战斗过程，所以拔线也能算出结果。同时也使用了悬浮窗进行显示。

### 什么情况会跳过

跳过的轮次预测和实际两边都不计入，保证两个数字的分母始终一致。

- **打尸体对手**（克尔苏加德）。它血量恒为 0，打赢了对手也不会掉血，会被误判成平。这种轮次整轮跳过。
- **在胜率出现前就拔线**。此时胜率还没算完，没有预测值可累加。
- 双方都掉血、或读不到血量。

### 统计范围

**从 HDT 启动算起**。

只有两种方式归零：点插件页面的**「重置统计」**按钮，或**重启 HDT**。

## 免责声明

插件只修改 HDT 本地的显示和记录，不影响你的真实天梯分数和对局结果。

全绿战绩器会**永久删除** HDT 本地的那部分对局记录。使用前请确认你接受这一点。

需要修改某些部分可以自行进行修改和编译。
